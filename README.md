# 📱 Digital Banking Application

A modern web-based digital banking application engineered to simplify daily financial management, track transactions, and deliver an intuitive banking experience in the browser.

## 🚀 Key Features
- **Account Dashboard:** View account balances and real-time activity.
- **Fund Transfers:** Securely send and receive money between accounts.
- **Transaction History:** Detailed log of past deposits, withdrawals, and transfers.
- **User Authentication:** Secure login interface to protect user session data.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage:** LocalStorage / SessionStorage
- **IDE:** Visual Studio Code

## 💻 How to Run
1. Clone this repository.
2. Open `index.html` directly in any web browser.
